## Portfolio Website
# Project Overview
This is a personal portfolio website designed and developed to showcase my projects, skills, and experience. Built using HTML, CSS, and JavaScript, the site serves as a digital resume and project gallery for potential employers, collaborators, and anyone interested in my work.

# Features
- Clean, responsive design with smooth navigation
- Project sections with live links and GitHub repositories
- About me section highlighting technical background and interests
- Contact section with social media links and email
- Custom CSS styling for a consistent and modern layout

# Usage Instructions
To view the website locally:

Clone the repository:
git clone https://github.com/sabrinalone45/portfolio-website.git

Navigate into the directory:
cd portfolio-website

Open index.html in any web browser.

You can also view the live site here:
https://sabrinalone45.github.io/portfolio-website
